# 课后思考：我在科研中如何使用 AI，以及如何核查它的输出

（学生：huangshiyan · 健康大数据 第 1 讲）

## 一、我准备在哪些科研环节使用 AI

结合我的研究方向（生命科学 / 健康大数据），我打算主要在以下环节借助 AI：

1. **文献检索与阅读**：快速定位相关文献、总结长文要点、辅助阅读英文文献。
2. **实验设计与数据分析**：检查统计方法是否合适、辅助实现分析代码（pandas 数据整理、描述性统计、绘图）。这是本课程后续会大量用到的环节。
3. **代码理解与调试**：让 AI 解释不熟悉的代码、解读报错信息、根据明确需求写一小段代码。正如本节课：让 AI 逐行解释 `groupby` / `count` / `mean`，再自己核对运行结果。
4. **写作辅助**：润色英文表达、生成图表说明。

## 二、我会怎样检查它的输出、避免误用

1. **代码必须自己运行**：AI 生成的代码我一定亲手跑一遍、对照预期结果核对，而不是只看它写得是否流畅。
2. **重要事实回到原文**：不直接相信 AI 给出的文献、数据和结论，关键信息回到原始文献或官方文档核实。
3. **用数据核查 AI 的建议**：例如本节课，AI 曾建议"把缺失值填成 0 再求平均"，我用表中的数字算出这会把处理组平均数从 130 拉低到约 86.7，判断这不合理，因此保留缺失值并同时报告有效测量数。
4. **保护隐私数据**：不上传病人信息、未公开实验数据或隐私内容；不把 API Key 写进代码或仓库。
5. **记录核查过程**：把"AI 建议了什么 → 我怎么核查 → 最终是否采用"写进 Notebook，形成可追溯的实验记录。
