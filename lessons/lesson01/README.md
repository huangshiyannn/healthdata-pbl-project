# Lesson 01：环境、VS Code、Codex 与 Git 入门

## 研究问题
搭建课程所需的开发环境，跑通第一个分析 notebook，理解 Git 版本追踪与提交记录的基本流程。

## 目录说明
| 路径 | 内容 |
|---|---|
| `data/` | 数据说明（本课无外部教学数据集） |
| `src/` | 入门 notebook `first_analysis.ipynb` 与说明 |
| `outputs/` | 运行产生的结果（如有） |
| `report/` | 作业证据清单与 AI 使用计划说明 |
| `materials/` | 课堂课件 |
| `reflection.md` | 本课反思 |

## 复现步骤
1. 按 `src/README.md` 准备 Python 环境。
2. 在 Jupyter/VS Code 中打开 `src/first_analysis.ipynb`，逐格运行。

## 证据链
入门练习以环境跑通为主；后续课程的结论按「报告 → outputs → src → data」追溯。
