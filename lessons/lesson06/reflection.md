# 项目反思（lesson06）

## 尝试过但失败 / 走不通的方案
- 早期直接在症状特征上跑 Bernoulli 朴素贝叶斯，未检查特征冗余与重复样本，指标受重复/相似向量影响；后冻结六特征分析口径，单独做重复样本对照实验，并把训练/验证/锁定测试集分开评价。
- 曾把概率输出当成校准良好的诊断概率，对照校准曲线后在报告中明确：朴素贝叶斯的条件独立假设并不严格成立，概率只作方法演示。

## 修改与理由
- 将数据准备、工具函数、分析 notebook 分离到 `src/`，指标表、预测表、阈值与校准图归入 `outputs/`，使每个评价结果都能回溯到对应脚本与输入特征。
- 锁定测试集仅在协议确定后评价一次，避免反复看测试集调参造成泄漏。

## 证据链自检
- 报告结论 → outputs → src → data：已打通。诊断表现与阈值/校准结论对应 `outputs/` 中指标表、预测表与 `fig1–fig3`，代码为 `src/naive-bayes-lab.ipynb`、`src/prepare_data.py`、`src/lab_utils.py`，输入为 `data/` 下炎症/肾病数据与字段说明。
- 是否存在只放截图、无源文件的图：否，图均由脚本生成。

## 局限与下一步
- 教学数据为小样本二分类，特征间条件独立假设并不严格成立；结果不支持临床诊断部署，也不外推到其他人群。
- 本研究不能回答的问题：不能证明模型可用于真实临床筛查，也不能比较在更大人群上的稳健性。
- 后续可改进方向：加入特征冗余与条件依赖的量化诊断，尝试概率校准方法，并在独立样本上复核阈值稳定性。
