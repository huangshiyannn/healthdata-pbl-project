# 项目反思（lesson08）

## 尝试过但失败 / 走不通的方案
- 早期在未做特征标准化的情况下直接比较线性核与 RBF 核 SVM，间隔与支持向量数量受量纲影响；后补充特征尺度对照实验，在统一标准化口径下比较 C 惩罚、核选择与间隔/支持向量的关系。
- 曾在测试集上反复调整 C 与核参数以追求更高表现，造成测试集泄漏；改为在验证/交叉验证阶段确定协议，测试标签仅锁定后评价一次。

## 修改与理由
- 将数据准备、工具函数、SVM 实验 notebook 与受控实验脚本分离到 `src/`，流程图、间隔/违例、C 扫描、核网格、尺度对照、ROC 与压力测试图归入 `outputs/`，使每个受控实验结论可回溯到脚本与输入。
- 保留教师参考分析脚本在 `materials/`，学生分析代码在 `src/`，区分教学参考与本人实现。

## 证据链自检
- 报告结论 → outputs → src → data：已打通。SVM 边界、margin、C/核/尺度结论对应 `outputs/fig1–fig8`，代码为 `src/svm-lab.ipynb`、`src/prepare_data.py`、`src/lab_utils.py`，输入为 `data/` 下脊柱生物力学数据与字段说明。
- 是否存在只放截图、无源文件的图：否，图均由脚本生成。

## 局限与下一步
- 教学数据为受控研究子集，测试标签仅在协议锁定后评价一次；课程不宣称这是全新独立验证，结果不支持临床部署或跨人群泛化。
- 本研究不能回答的问题：不能证明 SVM 在真实临床诊断中优于其他模型，也不能外推到不同人群或设备。
- 后续可改进方向：补充超参数网格的稳定性与重复划分结果，加入其他核函数对照，并在独立数据集上复核间隔与泛化表现。
