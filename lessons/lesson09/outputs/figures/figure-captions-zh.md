# 论文图表中文图注

## 主文图

**图1｜数据分区与分析流程。** 展示 UCI CTG 数据在本项目中的训练集、验证集和锁定测试集分区，以及各分区参与的分析。模型性能依据训练集与验证集合并后的 `recording_id` 分组五折交叉验证；预测稳定性通过训练录音级重抽样，在固定验证集上评估；测试集不确定性通过测试录音级重抽样估计。片段不等同于相互独立的患者，流程图也不代表外部验证。

**图2｜固定分区中的片段级类别构成。** 堆叠柱表示各分区的阴性（类别0）与阳性（类别1）片段数，柱顶标注该分区片段总数。计数来自样本流结果文件。数据单位是片段；这些计数不应解释为患者数或疾病患病率。

**图3｜按 `recording_id` 分组五折交叉验证的模型性能。** A，PR-AUC（按 `average_precision_score` 计算的 average precision）；B，ROC-AUC；C，平衡准确率。点表示五折均值，横向线段表示折间标准差（SD），并非置信区间。该比较是本数据与验证协议下的预测性能描述，不代表统计显著性、临床效用或因果效应。

**图4｜训练录音级 bootstrap 下单树、Bagging 与随机森林的预测稳定性。** 从209个训练录音中以录音为单位有放回抽样200次，每次拟合模型并对相同的424个验证片段预测。A，每个验证片段预测概率标准差的跨片段均值与中位数；B，重复拟合间类别预测发生翻转的片段比例。该结果衡量训练样本扰动下的预测稳定性，不是外部泛化能力或模型性能置信区间。

**图5｜验证协议敏感性与锁定测试集模型差异。** A，行级五折与 `recording_id` 分组五折交叉验证的 PR-AUC 描述性对照；连接线仅连接两种协议的估计值，不表示不确定区间。B，锁定测试集上随机森林相对预先固定对照模型的 average precision 与 ROC-AUC 差值；点和区间为以测试录音为单位的2000次 bootstrap 点估计与95%百分位区间（70个录音）。测试集结果不用于模型选择或调参；该分析不是外部验证，区间也未涵盖模型重新训练与模型选择的不确定性。

## 主要表格

**表1｜主要模型比较。** 展示 `recording_id` 分组五折交叉验证中各模型的主要性能指标。数值以均值±折间标准差（SD）表示，SD不是置信区间。PR-AUC按 average precision 计算；分类阈值相关指标按分析代码中预先设定的阈值计算。

**表2｜录音级 bootstrap 预测稳定性结果。** 汇总单树、Bagging 与随机森林在训练录音级 bootstrap 下的验证集预测稳定性指标。重抽样单位为训练录音，验证片段集合固定；这些指标不表示模型性能区间或跨机构泛化能力。
