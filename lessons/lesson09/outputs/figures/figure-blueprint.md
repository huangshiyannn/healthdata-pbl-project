## 主文图 1：数据与验证设计

- **回答的问题：** 分析流程如何安排，哪些数据用于模型比较、稳定性分析和锁定测试？
- **真实结果文件：** `05_分析结果/sample-flow.csv`、`data-quality.json`、`run-info.json`；设计规则核对 `analysis-plan.md` 与 `04_分析代码/ctg_analysis.py`。
- **面板作用：** 单面板流程示意。不画性能值或类别柱形图。显示固定 train、validation、locked test 三个分区及用途；train+validation 进入录音分组五折 CV，train 录音整群 bootstrap 后在固定 validation 预测，train+validation 拟合后对 locked test 一次评价，测试录音级 bootstrap 用于固定模型指标差值区间。流程框只标分区名称，不再重复各分区计数。
- **对应论文结论：** 主要性能、训练扰动稳定性和锁定测试来自不同分析环节；CV/重抽样遵循录音分组。
- **是否需要新增分析：** 否。只把现有设计和计数文件可确认的流程绘成图。
- **是否适合主文：** 是。它解释后续图表的分析单位和测试集使用方式。
- **不能推出：** 不能说明模型表现、患者数、临床代表性或外部泛化；流程图本身不能证明未记录的人工操作。

## 主文图 2：分区中的结局构成

- **回答的问题：** train、validation、locked test 三个片段分区的阳性/阴性数量和类别不平衡程度如何？
- **真实结果文件：** `05_分析结果/sample-flow.csv`、`data-quality.json`。数据为 train 1,279（108 阳性、1,171 阴性），validation 424（34、390），locked test 423（34、389）。
- **面板作用：** 单面板按分区作阳性/阴性堆叠柱形图，纵轴为片段数，柱段直接标注计数并在上方标总行数；图注同时说明片段不等同独立患者。不得从当前汇总表扩展成按患者、孕妇或临床亚组的分布。
- **对应论文结论：** 各固定分区均存在类别不平衡，支持将 PR-AUC 作为主要区分指标并报告类别相关指标。
- **是否需要新增分析：** 否。计数已存在于样本流和质量报告。
- **是否适合主文：** 有条件适合。仅当主文不再重复放“数据与分区概况”表时保留。若期刊版面紧或图 1/表 1 已列出同一组计数，则将图 2 移至补充材料，不重复呈现。
- **不能推出：** 不能据图推断患者患病率、目标临床人群患病率、数据代表性或分区间临床差异；这些是片段级标签计数。

## 主文图 3：录音分组交叉验证的模型性能

- **回答的问题：** 七个模型在按 `recording_id` 分组的开发集五折 CV 中，区分能力与固定阈值分类表现如何，指标排序是否一致？
- **真实结果文件：** `05_分析结果/cv-summary.csv` 中 `grouped_cv` 行；逐折来源为 `cv-fold-metrics.csv`。
- **面板作用：**
  - **A：** 七模型 PR-AUC（实际由 `average_precision_score` 计算，即 average precision）五折均值及折间 SD。
  - **B：** ROC-AUC 均值及折间 SD。
  - **C：** balanced accuracy 均值及折间 SD。
  - 各面板横轴模型顺序一致；误差线标明为折间 SD，不标 CI。敏感度/特异度的完整数值放主文表 1，不再增加面板。
- **对应论文结论：** 分组 CV 下模型表现存在指标间权衡：RF 平均 PR-AUC 最高（0.944），GB 平均 balanced accuracy 最高（0.928），LR 的 ROC-AUC（0.990）与树集成接近；没有单一模型在所有指标上领先。
- **是否需要新增分析：** 否。由既有汇总表绘图；如要显示实际各折散点，直接使用已保存的逐折结果，不重新拟合。
- **是否适合主文：** 是。它呈现预设主要性能结果。
- **不能推出：** 折间 SD 不是置信区间；均值排序不证明统计显著差异；不能推出临床效用、因果效应或外部泛化。

## 主文图 4：训练录音级 bootstrap 的预测稳定性

- **回答的问题：** 对训练录音整群重抽样时，单树、bagging、随机森林的验证片段概率预测波动和阈值类别翻转分别如何？
- **真实结果文件：** `05_分析结果/stability-summary.csv`、`stability-bootstrap-replicates.csv`。200 次 train 录音 bootstrap，在同一组 424 个 validation 片段上预测。
- **面板作用：**
  - **A：** 每模型逐样本概率 SD 的均值与中位数；两个统计量来自 summary CSV，直接以成对点显示，并在图注给出定义。最大 SD 可作为表注数值，不强行塞入图中。
  - **B：** 类别翻转率：单树 12.50%、bagging 10.38%、RF 7.55%。
  - 当前复现文件没有保存每个验证片段在每次重复中的完整预测概率，因此不画逐样本 SD 分布或 200 次预测轨迹。
- **对应论文结论：** 在本训练录音重抽样及固定 validation 条件下，bagging/RF 的若干预测扰动指标低于单树。
- **是否需要新增分析：** 否。均值、中位数、翻转率均已保存。若希望绘制验证片段级分布，则需要新增保存逐片段重复预测的分析，现阶段不规划。
- **是否适合主文：** 是。稳定性是论文问题之一，且与图 3 的性能维度不同。
- **不能推出：** 不能推断新录音、新医院或患者上的外部泛化、临床安全性或性能 CI；也不能将三模型结果推广到未做该稳定性分析的其他模型。

## 主文图 5：验证协议敏感性与锁定测试差值不确定性

- **回答的问题：** 模型比较对评估协议有多敏感，锁定测试录音上关键模型差值的不确定性有多大？两部分共同呈现证据对验证设计和测试录音抽样的稳健程度。
- **真实结果文件：** 面板 A 用 `cv-summary.csv` 与 `cv-fold-metrics.csv` 的 `row_cv`/`grouped_cv` 结果；面板 B 用 `test-paired-differences.csv`、`test-cluster-bootstrap-summary.csv`，必要时查 `test-cluster-bootstrap-replicates.csv`。
- **面板作用：**
  - **A：** 七模型逐行与分组 CV 的 PR-AUC 配对点/线图，显示每模型两种协议均值及描述性差异。图注说明逐行结果是敏感性分析，不是主估计；不能把折间 SD 当作差值区间。
  - **B：** RF-LR、RF-RBF-SVM 的测试集 PR-AUC 和 ROC-AUC 点差及 95% 百分位录音级 bootstrap 区间；以零差值为参考线，标示 2,000/2,000 有效重复。图注说明抽样单位是 70 个测试录音，模型固定。
- **对应论文结论：** 逐行 CV 的 PR-AUC 在本数据中均高于分组 CV；测试集 RF-LR 差值区间为正，RF-SVM 区间较宽且跨零或接近零。证据应按协议和比较对象谨慎解读。
- **是否需要新增分析：** 否。两面板所需结果均已计算并保存。
- **是否适合主文：** 可以保留，但属于主文五图中最可删的一张。若版面或叙事负担过重，优先把整张图移至补充材料；不能只保留测试点估计而删去不确定性区间。
- **不能推出：** 逐行与分组均值之差不是通用偏倚量；测试集是同一来源的锁定留出分区，不是外部验证；bootstrap 区间不含重新训练、选模及新来源不确定性；不能看图后选定“赢家”。

## 全图统一样式和导出要求

- **中文字体：** 优先使用已安装的思源黑体/Source Han Sans SC 或 Noto Sans CJK SC；若环境未安装，使用 Microsoft YaHei。绘图前检查字体实际可用，避免中文缺字；同一交付批次全图固定一种字体。
- **颜色：** 使用可区分且色盲相对友好的固定色板，避免单色系：单树 `#0072B2`、bagging `#009E73`、随机森林 `#D55E00`、AdaBoost `#CC79A7`、梯度提升 `#E69F00`、逻辑回归 `#56B4E9`、RBF-SVM `#333333`。类别阳性用橙红 `#D55E00`、阴性用蓝 `#0072B2`；灰阶打印时辅以不同线型/填充纹理和直接标签。
- **线条与标记：** 轴/网格线宽 0.5–0.7 pt，主要曲线/误差线 1.0–1.2 pt，数据点直径约 4–5 pt；不使用阴影、渐变或 3D 效果。误差线帽宽保持一致。
- **字体层级：** 最终版面尺寸下，轴标题/图例 8–9 pt，刻度和图注 7.5–8.5 pt，面板标签 10 pt 粗体；避免依赖颜色传达唯一信息。
- **图例：** 全文模型名及顺序固定为单树、bagging、随机森林、AdaBoost、梯度提升、逻辑回归、RBF-SVM；多个面板共享一个图例，优先置于图下方。敏感性图用线型区分 row/group；测试区间图标明零差值线。
- **面板标签：** 使用大写 A、B、C，左上对齐、粗体、无句点；同图标签位置、字号一致。
- **尺寸与文件：** 双栏宽图按 180 mm 宽、单栏图约 86 mm 宽设计；高度以图内文字可读且不超过约 220 mm 为限。优先交付 PDF/SVG 矢量文件；同时需要位图时导出 600 dpi TIFF。字体嵌入/转曲策略按目标期刊要求复核。目标期刊未确定，以上为统一工作尺寸而非期刊最终规范。
